# BandSpace Interview

Учебный проект: видеособеседования 1 на 1 на React, TypeScript, WebRTC и WebSocket.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для проверки откройте его в двух отдельных окнах или профилях браузера и нажмите «Войти в видеокомнату» в обоих.

Разрешите браузеру доступ к камере и микрофону. Если браузер не показывает запрос разрешений, проверьте настройки сайта.

## Сборка

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

1. Создайте новый пустой репозиторий, например `bandspace-interview`.
2. Загрузите в него все файлы этого проекта.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **GitHub Actions**.
5. Отправьте изменения в ветку `main`. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт.

## Как устроено соединение

- WebSocket `wss://inai-col3.fishrungames.com/signaling/` используется только как signaling-канал.
- Через него участники пересылают `hello`, `hello-ack`, `offer`, `answer` и `ice-candidate`.
- WebRTC `RTCPeerConnection` передаёт аудио и видео между браузерами.
- Для ICE добавлены публичные STUN-серверы Google.
- Для определения инициатора используется сравнение случайных ID: offer создаёт только один из двух браузеров.

## Важно

- Сервер signaling по условию поддерживает только двух подключённых клиентов. Если подключится третий, сервер может отключить первого.
- Доступ к камере/микрофону работает на `localhost` и на HTTPS-сайтах.
- В некоторых сетях для связи может потребоваться TURN-сервер. В задании TURN не предоставлен, поэтому проект использует STUN.
- Проект предназначен для учебной демонстрации. Перед использованием для реальных собеседований потребуется дополнительная обработка переподключений, ошибок и приватности.
